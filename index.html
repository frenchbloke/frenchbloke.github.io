frenchbloke

Browser-based audio experiments. All single HTML files — right-click, save as, use anywhere.

glue

https://frenchbloke.github.io/glue/

After weeks of disassembling audio files with some rate of precision, I thought what else can be done with it that isn't on any of the things below this one? Then I thought, what if you could load a MIDI file and use the sliced beats to play that MIDI file? And what better thing to test it than Blue Monday. (you can import other MIDI files) amusing for a few minutes.

amstradt

https://frenchbloke.github.io/amstradt/amstradt.html

Imagine if Amstrad made the shittiest sounding sample / hold / looper. Imagine no more. It's hissy, it's meant to be.

temute

https://frenchbloke.github.io/temute/

If Temu made audio software. This takes the idea of locking beat 1, 5, 9, 13 etc of something 4/4, then takes beat 2 and smears it across 2, 3 & 4 etc. Ultimately pointless but it gave me a few ideas at least.

DJMince

https://frenchbloke.github.io/DJMince/

This one is just stupid but proved a point. Import one track, import another. It will use track one (unless you hit shuffle) as the basis for what you hear — so beats 1, 5, 9, 13, the doof bit — and will use bits of both 1 & 2 to fill up the gaps. Sounds like a car crash but fun when used with non-doof doof.

disappointment

https://frenchbloke.github.io/disappointment/

Instant (well, once it calculated the time / format shifting to get the original bpm) schaffel and waltzes and 7/8 and chaos.

aspire

https://frenchbloke.github.io/aspire/

A synthesised choir that's triggered when satellites pass overhead — the data in this is from last week so will lose its reliability.

precentor

https://frenchbloke.github.io/precentor/

The first choir related thing I tried. You can play this one using the a–j keys.

orrery

https://frenchbloke.github.io/orrery/Orrery.html

Took the choir idea then added the Eno / Koan Pro random generative pattern looping cycle thing. It spins, it sings.

hamstrad

https://frenchbloke.github.io/hamstrad/

It looks at an audio track really hard.
It then looks at another and makes the foolish decision to try and make the first one into the second one by chopping it all up and gluing it back together.

These are all HTML files so you can right-click, save as, and use them wherever you want.
